# Tópicos Especiais em Redes de Computadores

Trabalho final de Engenharia de Computação — UERJ/IPRJ.

## Simulador 3D

A topologia pode ser explorada no navegador pelo [simulador 3D interativo](https://manoelpiovesan.github.io/terc/). Arraste para girar, aproxime com a roda do mouse, selecione os equipamentos para consultar informações e use os filtros para visualizar infraestrutura, VLANs e rotas. O botão de simulação anima um pacote entre o Wi-Fi 1 e a Internet.

Os arquivos do simulador são `index.html`, `styles.css` e `app.js`. A aplicação usa Three.js via CDN, sem etapa de build.
